# msx-zip0

LG TV の Media Station X から [ZIP0](https://zip0.com/) を開くための設定です。

## Start Parameter

```text
https://raw.githubusercontent.com/fmokutagawa-design/msx-zip0/main/start.json
```

Media Station X で HTTPS（Security Lock）を有効にして設定してください。

外部HTMLサイトを `link:` アクションで開くため、ZIP0からMedia Station Xへ戻れない場合はアプリを終了して再起動してください。
